# My Professional Portfolio

Hi! I'm Majid Khan, a Full-Stack Developer. This project is my personal portfolio website, built to showcase my skills and projects.

## 🚀 Tech Stack
- **Frontend:** React.js, Tailwind CSS
- **Build Tool:** Vite
- **Deployment:** GitHub Pages via GitHub Actions (Automated CI/CD)

## ✨ Features Added
- **Modern Header:** Created a responsive navigation system for the portfolio.
- **Automated Deployment:** Configured a GitHub Actions workflow to automatically build and deploy the site whenever code is pushed to the `main` branch.
